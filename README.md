# Odin Recipes

My first project from [The Odin Project](https://www.theodinproject.com/), built using HTML.

The goal of this project was to create a recipe website featuring a homepage and separate pages for individual recipes.

## Recipes Included

This website features three Sri Lankan dishes:

- Kottu
- Fried Rice
- Kiribath

## Features

Each recipe page includes:
- An image of the dish.
- A brief description of the recipe.
- A list of required ingredients.
- Step-by-step cooking instructions.
- A link to navigate back to the homepage.

## Technologies Used

- HTML5
